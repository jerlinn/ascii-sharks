# 程序化生命的设计原则

先确定主体，再分配画面密度。陪体收敛种类，以疏密、尺度差异和留白组织视线。

模拟描述运动，几何描述形体，渲染表达材质。保持单向数据流，让外观变化与行为规则各自独立。

周期运动从角度和连续相位出发，再计算屏幕投影。节奏变化通过频率与振幅渐变产生，状态切换保留运动惯性。

大小、对比度、遮挡和投影由同一深度关系驱动。

个体拥有独立节奏和行为倾向，在探索、接近与停留之间选择。用局部互动形成群体变化，保留持续游离的个体。

## Gotchas

飞行保持轨迹切线连续，身体朝向与速度方向一致。限制角速度和角加速度，换目标与受惊时保留当前位置、速度和转向惯性。

边界避让提前转弯并减速；接近停留点时先减速，再连续跟随目标。位置按速度积分，约束通过运动过程满足。

拍动、滑翔与停栖共用连续相位，平滑调整频率、振幅与姿态，衔接时保留角度和角速度。

依附对象共用位置与位移来源，模拟与渲染读取同一运动状态。

透明采样单元严格对齐边界，叠色遵循图层关系。
